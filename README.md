# Nexus Pay

A credit card processing system designed to process card transactions, analyze grace periods, and manage financial activities efficiently.

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/RAMALAKSHMI3106/Nexus_Pay.git
```

2. Navigate to the project directory:

```bash
cd Nexus_Pay
```

3. Install the required dependencies:

```bash
npm install
```

4. Configure the MySQL database.

5. Start the application:

```bash
npm start
```

6. Open the application in your browser.

1. User authentication and login.
2. Credit card verification and processing.
3. Wallet management.
4. Transaction history tracking.
5. Grace period analysis.
6. Analytics dashboard.
